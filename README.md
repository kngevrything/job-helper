# Job Helper

A personal job search toolkit. Currently a local-only job application tracker (web app); a companion Chrome extension is a work in progress and not recommended for use yet.

The web app lives in [`job-tracker/`](./job-tracker), including full setup instructions, environment variables, testing, and known limitations. See that folder's [README](./job-tracker/README.md) to run it.
